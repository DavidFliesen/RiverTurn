# Riverturn
Fly Tying Field School by ARTEZIQ. First prototype, v0.1.0.

Riverturn refers to the rotary motion of the vise and a bend in the water where the finished fly is fished. The original SVG mark combines a current loop and a hook, with copper accents indicating the direction of the turn.

## Run or deploy

Serve the web files over localhost for development or over HTTPS for installation and offline use. In this source repository the web root is `dist/`. In the portable ZIP the web files are already at the root.

Use `python3 -m http.server 8000 --directory dist` from the source repository, or `python3 -m http.server 8000` from the extracted ZIP. Open http://localhost:8000. For static hosting, upload the web root as-is. There is no build step or external runtime dependency.

On iPad or iPhone, use Safari's Share menu and Add to Home Screen. The first successful visit prepares the app shell and built-in content for offline use. Linked instructional videos require an internet connection. Lesson completion, the materials checklist, bench position, lab comparison and challenge draft are stored in this browser.

## Content and pilot scope

Norvise and Norm Norlander instructional videos are credited outbound links. The Riverturn app is an independent ARTEZIQ prototype. Community sharing and voting, podcast audio, live events and central Ladybug feedback are future pilot work. Riverturn is a working brand pending clearance before public release.
